# Paradise Nursery Shopping Application

Paradise Nursery is a React-based web application designed for plant lovers.  
It allows users to browse a variety of indoor and outdoor plants, view details, add items to their cart, and manage purchases easily.

## Project Details
- **Project Name:** Paradise Nursery Shopping Application  
- **Technology Used:** React.js, Redux Toolkit, CSS  
- **Purpose:** To demonstrate front-end development skills by building a functional e-commerce plant shop interface.  
- **Developer:** Harsh (Vishwakarma University)

## Features
- Product listing page with plant details  
- Shopping cart with add, remove, and update quantity functions  
- Attractive landing page with background image and “Get Started” button  
- About Us section describing the company
